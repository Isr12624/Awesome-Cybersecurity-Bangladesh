# Awesome Cybersecurity Bangladesh Ecosystem

A searchable ecosystem for Bangladesh cybersecurity companies, universities, resources, communities, and professionals.

## Features

- Structured JSON data in `/data`
- Search and filters (type, location, focus area)
- Detail pages for each entity
- REST API endpoints for integrations
- Statistics dashboard

## Project structure

- `src/app` - Next.js app routes and API routes
- `data` - ecosystem datasets
- `docs/API.md` - API reference
- `docs/SETUP.md` - local setup and deployment
- `docs/DATA_SCHEMA.md` - schema documentation
- `CONTRIBUTING.md` - contribution workflow

## Quick start

```bash
npm install
npm run dev
```
